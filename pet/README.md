# 🐱 Antigravity 灵动桌面小宠物 (Gemini Mascot)

为 **Google Antigravity** 打造的现代、轻量化、高颜值桌面随行助手。集**实时模型额度感知**、**任务完成/异常非侵入式弹窗**与**一键多账号无感安全换号**于一体。

---

## 🌟 核心特性

- 🐾 **灵动透明浮窗 (Gemini Mascot)**：
  - 基于现代轻量渲染管线，支持真正的背景透明抗锯齿。
  - 鼠标自由拖拽、位置记忆、窗口置顶切换与系统托盘（System Tray）常驻。
  - 多形态灵动状态切换：`idle` (惬意待命)、`thinking` (思考运算中)、`success` (任务大功告成)、`warning` (额度告警)。
- 🎨 **自定义形象热替换**：
  - 默认搭载灵动 Gemini 蓝色吉祥物形象。
  - 支持导入个人专属形象文件（**PNG / Animated GIF / WebP / SVG**）。
  - 内置多款预设皮肤：`gemini_sparkle`（星芒晶体）、`quantum_bot`（量子机甲）、`cosmic_orb`（星系能量球）。
- 📊 **反重力额度实时感知**：
  - 自动探测本地 `~/.gemini` 模型配额与调用频次。
  - 悬浮宠徽标与状态直观反馈剩余额度，免去频繁进入控制台查看。
- 🔔 **任务完成/告警弹窗提示**：
  - 耗时较长的后台编码任务完成或构建报错时，触发轻量通知气泡，不抢夺操作系统焦点。
  - 额度跌破警戒阈值时主动提醒。
- ⚡ **一键便携换号 (Multi-Account Switcher)**：
  - 本地维护多个独立的账号 Profile（`dev`, `work`, `backup` 等）。
  - 底层采用 Windows 原生 **Win32 `MoveFileExW`** 硬件级原子替换协议与微秒级防碰撞备份，彻底杜绝换号中途掉电导致凭证损坏。
  - 一键毫秒级切换，Antigravity 客户端无感刷新。

## 🚀 启动与使用方式

### 方式一：随汉化脚本一键启用（推荐）
运行项目根目录的 `install-windows.bat`：
- 在汉化成功后，脚本会主动询问是否启动桌面小宠物并创建桌面快捷方式。
- 或在主菜单输入 `[9]` 进入小宠物专属管理面板。

### 方式二：双击根目录启动脚本
双击项目根目录下的：
```cmd
launch-pet.bat
```
脚本将自动采用无黑框模式（`pythonw`）在后台启动小宠物并驻留托盘。

### 方式三：命令行直接运行
```bash
python pet/run_pet.py
```
- 运行 30 项自检冒烟测试：
  ```bash
  python pet/run_pet.py --smoke
  ```
- 运行 98 项全覆盖端到端自动化测试：
  ```bash
  python pet/test_account_switcher.py
  ```

## 🎨 更换自定义小宠物形象

1. 右键小宠物托盘图标或通过界面设置；
2. 选择本地任意一张透明底的图片（支持 `.png`, `.gif`, `.webp`, `.svg`）；
3. 形象将立即热加载渲染，无需重启程序！
4. 你也可以直接将新图片放置于 `pet/frontend/assets/` 目录下。

---

## 🧪 自动化测试与工程可靠性

本项目包含严苛的自动化测试套件：
- `test_account_switcher.py`：覆盖 Tier 1~4 共 **98 项端到端用例**（100% 满分通过）。
- `run_pet.py --smoke`：**30 项冒烟测试**（100% 满分通过）。
- 具备完全纯净的沙盒隔离测试机制（Hermetic Sandbox），测试过程中绝不影响您真实的 `~/.gemini` 运行凭证。
