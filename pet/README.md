# 🐾 Antigravity 灵动桌面小宠物 (Gemini Mascot)

为 **Google Antigravity** 打造的现代、极简透明、高颜值桌面随行助手。集**真实官方双轨配额感知**、**任务完成/异常非侵入式弹窗**、**彻底防连击崩溃安全拖拽**、**随主程序自动启动**与**一键多账号无感安全换号**于一体。

参考了开源项目 [Awesome Codex Pet](https://github.com/legeling/awesome-codex-pet)（https://codexpet.top）的设计哲学，彻底消除任何影响视线的黑色/灰色方框背景。

## 🌟 核心特性与架构升级

### 1. 纯透明灵动桌面随行伴侣 (Codex Pet 像素风格)
- **真·全透明壁纸漫步**：基于 Windows DWM 硬件级透明层，完全剔除所有背景底色、卡片阴影与外边框，小宠物如同直接漫步在您的桌面壁纸上。
- **生动多动作帧动画**：
  - `idle`：悠闲呼吸与眨眼；
  - `thinking`：侧头好奇思考（智能体运行复杂任务时联动）；
  - `task_finished`：高举双手欢呼跳跃（任务完成或点击互动时触发）；
  - `quota_low`：警惕发愁提醒（额度告警时触发）。
- **趣味中文对白气泡**：鼠标悬停或轻点宠物，头顶即刻弹出幽默风趣的对白互动。

### 2. 真实 Antigravity 双轨配额 100% 对齐现实
- **官方凭据直连**：从 Windows Credential Manager (`gemini:antigravity`) 安全提取当前登录态，直连官方配额摘要端点；
- **真实账户信息展示**：准确呈现当前登录的用户名（如 `tao quan`）、头像与邮箱地址；
- **官方双轨结构完整呈现**：
  - ✦ **Gemini 模型组 (Flash, Pro)**：专属 5 小时配额与每周配额进度条（健康绿 / 适中黄 / 告急红）及绝对恢复时间（如“5小时配额将于 4小时20分钟 后全额恢复”）；
  - ✦ **Claude & GPT 顶级模型组 (Sonnet, Opus, GPT-OSS)**：专属 5 小时配额与每周配额进度及重置倒计时；
- **防限流安全防护**：内置 5 分钟懒加载安全缓存，严禁高频轮询打崩服务端，杜绝 429 被限流风险；绝不私自调用 refresh token，确保宿主登录态持久稳定。

### 3. 彻底根除“多次点击容易崩溃” Bug
- **事件彻底解耦**：
  - `mousedown` 仅记录初始坐标，**绝不调用任何操作系统拖拽 API**；
  - 仅当鼠标按住并在屏幕上**物理位移超过 5 像素**时，才判定为“用户有意拖拽”，触发一次 Win32 `start_drag`；
  - 纯点击（位移 ≤ 5px）触发萌宠欢呼庆祝与对白互动，**0 Win32 消息循环介入**，彻底切断连击死锁与闪退崩溃路径；
- **后端单调时钟节流与互斥锁 (`threading.Lock`)**：后端 `start_drag` 引入非阻塞互斥锁与 200ms 时间窗严格节流；
- **Windows 全局命名互斥锁 (`Global\AntigravityPet_SingleInstance_Mutex`)**：保证在系统中始终保持单实例运行，避免多进程重叠或冲突。

### 4. 弹窗 2 秒自动平滑消失（告别遮脸与永不消失）
- **严格单实例限制**：同一时间屏幕至多只允许保留一个 Toast，新通知弹出瞬间平滑替换旧通知，绝不重叠堆叠 3 层；
- **2.0 秒平滑渐隐**：倒计时进度条与卡片消失时间严格对齐，到期自动平滑滑出；
- **400ms 鼠标离开宽限期**：鼠标移出卡片后 400ms 恢复自动关闭，不再因一次划过而永久卡死在屏幕中央；
- **3.5 秒硬超时熔断**：即使发生意外的 DOM 阻塞，全局定时器将在 3.5 秒后强行将卡片从页面移除；
- **形象切换零遮挡**：移除了切换形象时的全局弹窗，改为宠物头顶轻快自空气泡（例如：“形象已切换至：派蒙”），视野开阔无遮挡。

### 5. 随 Antigravity 启动自动运行与彻底卸载
- **可选注入 (`scripts/patch_antigravity.py`)**：仅在用户选择“全能汉化补丁”时挂载自启守护逻辑，用户选择“纯净汉化补丁”时绝不注入任何代码；
- **全方位容错保护**：外层由严格的 `try...catch` 保护，**绝对不会阻碍 Antigravity 正常启动**；
- **UI 与托盘双控开关**：
  - **右上角设置面板（齿轮按钮）**：提供“随 Antigravity 启动自动运行”切换开关，设置即时持久化到 `~/.gemini/pet_config.json`；
  - **右键系统托盘图标**：同步提供“随主程序自启”勾选项，并增加“彻底退出并关闭自启动”菜单项；
- **一键彻底卸载（剥离自启 Hook）**：
  - 在汉化管理器输入 `10` 进入桌面宠物专区，选择 `[4] 彻底卸载桌面宠物`；
  - 或命令行直接执行 `python scripts/patch_antigravity.py uninstall-pet`；
  - 自动杀掉后台进程、从 `app.asar` 彻底剥离自启 Hook（保留中文汉化）、清理桌面快捷方式与渲染沙盒。

### 6. Awesome Codex Pet 社区生态支持与自由换装
- 深度兼容 [awesome-codex-pet](https://github.com/legeling/awesome-codex-pet) 社区 255+ 款桌宠；
- 内置精选热门预设：**Gemini 灵动像素星灵**（原创动态）、**派蒙**（原神经典）、**哆啦A梦**（童年经典）、**Gemini 绒绒棉花糖**；
- 支持一键导入本地任意 **Animated GIF / WebP / PNG / SVG**，拖放至桌宠身上即可瞬间热加载变身！

### 7. 一键便携安全换号 (Multi-Account Switcher)
- 本地维护多个独立的账号 Profile（`dev`, `work`, `backup` 等）；
- 底层采用 Windows 原生 **Win32 `MoveFileExW`** 硬件级原子替换协议与微秒级防碰撞备份，彻底杜绝换号中途掉电导致凭证损坏；
- 一键毫秒级切换，Antigravity 客户端无感刷新。

## 🚀 启动与使用方式

### 方式一：随 Antigravity 启动自动运行（全能版）
安装汉化补丁时选择 `[2] 安装简体中文全能补丁`，之后每次打开 Antigravity 客户端将自动无感拉起桌面宠物。随时可在右上角设置面板或系统托盘取消自启。

### 方式二：随汉化脚本一键管理与彻底卸载
运行项目根目录的 `install-windows.bat`：
- 在主菜单输入 `[10]` 进入小宠物专属管理面板；
- 可选择启动、创建快捷方式、运行自检，或执行 **`[4] 彻底卸载桌面宠物`**。

### 方式三：双击根目录启动脚本
双击项目根目录下的：
```cmd
launch-pet.bat
```
脚本将自动采用无黑框模式（`pythonw`）在后台启动小宠物并驻留托盘。

### 方式四：命令行直接运行或卸载
- 启动：
  ```bash
  python pet/run_pet.py
  ```
- 彻底卸载与剥离自启 Hook：
  ```bash
  python scripts/patch_antigravity.py uninstall-pet
  ```
