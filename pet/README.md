# 🐱 Antigravity 灵动桌面小宠物 (Gemini Mascot)

为 **Google Antigravity** 打造的现代、轻量化、高颜值桌面随行助手。集**实时模型额度感知**、**任务完成/异常非侵入式弹窗**与**一键多账号无感安全换号**于一体。

---

## 🌟 核心特性

- 🐾 **纯透明灵动桌面随行伴侣 (Codex Pet 像素风格)**：
  - 基于真正的 Windows DWM 全域 Alpha 透明层，彻底去除方框、底色与灰边，宠物如同直接漫步在壁纸上。
  - **原生 Win32 零延迟硬件级拖拽**：按下鼠标由系统内核级接管，144Hz 丝滑拖曳，彻底消除传统 JS 拖拽与点击卡顿。
  - **纯天然动态帧动作**：`idle` (呼吸与眨眼)、`thinking` (好奇侧头思考)、`task_finished` (欢呼跳跃庆祝)、`quota_low` (警惕发愁提醒)。
  - **趣味互动对话气泡**：鼠标悬停或点击宠物时即刻弹出趣味中文互动对白，伴随开心跳跃反馈。
- 🎨 **Awesome Codex Pet 社区生态与形象无缝切换**：
  - 深度兼容 [awesome-codex-pet](https://github.com/legeling/awesome-codex-pet) 社区 255+ 款桌宠。
  - 内置精选热门预设：**Gemini 灵动像素星灵**（原创动态）、**派蒙**（原神经典）、**哆啦A梦**（童年经典）、**Gemini 绒绒棉花糖**。
  - 支持一键导入本地任意 **Animated GIF / WebP / PNG / SVG**，拖放至桌宠身上即可瞬间变身！
- 📊 **反重力额度实时感知**：
  - 极简半透明额度胶囊紧随宠物，自动感知本地 `~/.gemini` 模型配额与调用频次。
  - 点击胶囊即刻平滑展开详细 Token 与各模型请求数明细。
- 🔔 **任务完成/告警弹窗提示**：
  - 耗时较长的后台编码任务完成或构建报错时，触发轻量通知气泡，不抢夺操作系统焦点。
  - 额度跌破 20% 警戒阈值时主动提醒并建议换号。
- ⚡ **一键便携换号 (Multi-Account Switcher)**：
  - 本地维护多个独立的账号 Profile（`dev`, `work`, `backup` 等）。
  - 底层采用 Windows 原生 **Win32 `MoveFileExW`** 硬件级原子替换协议与微秒级防碰撞备份，彻底杜绝换号中途掉电导致凭证损坏。
  - 一键毫秒级切换，Antigravity 客户端无感刷新。

## 🚀 启动与使用方式

### 方式一：随汉化脚本一键启用（推荐）
运行项目根目录的 `install-windows.bat`：
- 在汉化成功后，脚本会主动询问是否启动桌面小宠物并创建桌面快捷方式。
- 或在主菜单输入 `[9]` 进入小宠物专属管理面板。

### 方式二：双击根目录启动脚本
双击项目根目录下的：
```cmd
launch-pet.bat
```
脚本将自动采用无黑框模式（`pythonw`）在后台启动小宠物并驻留托盘。

### 方式三：命令行直接运行
```bash
python pet/run_pet.py
```
- 运行 30 项自检冒烟测试：
  ```bash
  python pet/run_pet.py --smoke
  ```
- 运行 98 项全覆盖端到端自动化测试：
  ```bash
  python pet/test_account_switcher.py
  ```

## 🎨 更换自定义小宠物形象

1. 右键小宠物托盘图标或通过界面设置；
2. 选择本地任意一张透明底的图片（支持 `.png`, `.gif`, `.webp`, `.svg`）；
3. 形象将立即热加载渲染，无需重启程序！
4. 你也可以直接将新图片放置于 `pet/frontend/assets/` 目录下。

## 🧪 自动化测试与工程可靠性

本项目包含严苛的自动化测试套件：
- `test_account_switcher.py`：覆盖 Tier 1~4 共 **98 项端到端用例**（100% 满分通过）。
- `run_pet.py --smoke`：**30 项冒烟测试**（100% 满分通过）。
- 具备完全纯净的沙盒隔离测试机制（Hermetic Sandbox），测试过程中绝不影响您真实的 `~/.gemini` 运行凭证。
